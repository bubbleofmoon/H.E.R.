# Prompts and participation modes

Read for personas, roles, prompt delivery, scheduling, chat, closed-agent interactions, reply timing or slang learning.

## Prompt rendering, personas and roles

- **Compat/CLI wrapping:** wrapped once at delivery with current-time line (`time.zone` local time + label; `host` follows machine/`TZ`; IANA follows calendar), confirmed slang, wake prompt. Order: role (closed-agent), persona (`【人设】`, companion), identity, token, bootstrap initial prompt, fixed guidance, state, reason tail. Live reserved2 uses briefing + wake delta; reminders keep own body.
- **Automatic recall (`memory::recall`):** `<= memory.inject.relatedTopK` (3, cap 5/wake); `<4` alnum/Han chars recalls nothing. Sparse strips Chinese stopwords (needs `>=2` shared terms `>=4` distinct chars, `>=1` identifier `>=4` alnum, or `>=1` word `>=6` chars); semantic embeds message + `<=4` speaker names + latest topic (unavailable falls back to sparse with `<=0.05` pin/importance/recency/use boost). Never padded; excludes session-generation `recalled` IDs (kept on same-gen full refresh, reset on new gen/session/epoch; DSH holds on accept, harness on canonical wake completion) + index hint; off if `memory.enabled` false. Compat holds nothing back; preview hides DSH-held recall; reminders/`build_text_only` carry none. Hit counts increment +1 on accepted delivery only (DSH accept, harness 1st usable response, CLI answer). Cosine ceiling/calibration: `docs/agents/mcp-memory.md`.
- **Personas (`persona.rs`):** `<data>/personas.json` (v1, `locks/personas.lock`; damaged -> 503, no persona, never repaired). Version fields: `name`, `core`, `notes`, `compact`, `names`, `failureLine`, `traits.neediness` (0-3, default 1), `editMode` (`auto`/`manual`, default `auto`), `autoRules` (`parts` ⊆ `core`/`notes`/`compact`/`names`/`traits`, `perWeek` 0-20, `monthlyDriftPause`, `notify`), `source`, `approved` (notes/compact/traits stored-only; identical save -> `unchanged: true`; max 50 versions pruning oldest unapproved, never active/newest).
  - Equal `core`+`compact` to active takes effect at once; else awaits approval (older approval = rollback). Assignment (`default` + canonical `overrides`) allows only `approved: true` + non-empty `name`/`core` (assigned cannot delete). Companion modes render `【人设】<name>\n<core>` once (`prompt::identity_core`/`briefing::persona_core`/`identity_hint_v1`; cut at `role.maxInjectChars` 6000 [1000-20000] UTF-16 until #18; none in reminders). Assignment change bumps briefing generation on changed mapped convs -> full briefing in same session.
  - Approval refuses 409 if `core > 1500` (`CORE_TOKENS_MAX`) or `compact > 300` (`COMPACT_TOKENS_MAX`) via `briefing::estimate_tokens` (rollback/import/duplicate skip budget; duplicate keeps `approved`), or on name collision (`GET /api/personas/item` adds `coreTokens`, `compactTokens`, `budgets`). Mid-render bump re-prepares once (`prompt::WAKE_BRIEFING_CHANGED`, no alert); failed re-briefs stay in `rebriefDue` (`GET /api/personas`, UI, `/persona`) until next assignment. `POST /api/personas/import-roles` imports `resources/roles/*.md` reserved2 views (then 409 once `importedRolesAt` set). Default fixture: `her/tests/fixtures/persona/xiaojingyu-v1.json` (`persona::tests::the_published_default_persona_is_within_budgets_and_approvable`).
- **Persona `failureLine`:** optional single line `<=160` UTF-16 (blank/null = silence; omit keeps; duplicate copies; line-only edit immediate). On terminal failed companion turn, sends `<=1` literal OneBot CQ-escaped bubble via recorded send after mode/access/authority/mute/silence/outbound checks (blocked by pending verify, existing reply, cancel or supersession; excluded from prompts/history/reports; never resent).
- **Persona wake words (`wake_words.rs`):** reserved2 ingress reads active persona `names` (fallback `[name]`, `[]` = off) as `keyword:<name>` (closed-agent/unassigned/damaged = none). `triggers.dropNames` via `qq_set_wake_config` (list replaces, non-list clears, omitted keeps; `<=10` names, `<=40` scalars; persona `names` `<=40` UTF-16) suppresses individual names; `keywords` follow deduped case-insensitively. Default/no-action/missed-closure/`wake::ensure_wakeable` resets keep `dropNames` (missed-closure clears `keywords`); `/reset` or console reset clears `keywords`, `dropNames`, `wakeWordLog` (log ids restart at 1); idle rotation keeps them. Word changes atomically append `{id, at, by (her|console|undo), added, removed, [undoes]}` (newest 20) to `wakeWordLog` in `social-v2.json`. `GET /api/personas/wake-words?conversation=`; `POST /api/personas/wake-words/undo {conversation, id}` (social gate) refuses 409 on state mismatch, no stored trigger left (`ensure_wakeable` ignores persona names, counts speaker IDs), `>50` `keywords` (`KEYWORDS_MAX`) or `>10` `dropNames`. Full briefing renders `【名字唤醒】` in groups only (`forYou` ignores persona names). Console omits blank `names`; API `names: []` clears.
- **Closed-agent roles:** conv -> role-group -> default -> current-role (`resources/roles`; Han precede Latin via `role_han_order.txt`, Latin case-insensitive; card hint keeps mode sections, drops 1st-gen cmds, normalizes example spaces).
- **Initial prompts (`initial_prompts.rs`):** `initial-prompts.json` (UTF-16 limits; damaged = read-only). 1st msg/poke atomically claims bootstrap; reset/replace clears claim. Compat/CLI injection follows claim; live briefings always include bounded operator background.
- **Recommendations & CLI `[SILENT]`:** `socialV2.provideRecommendations` (default true) gates `qq_get_prompt` `recommended` and `wake.recommendedHint`/`send.recommendedHint` (default empty). CLI backends may return `[SILENT]` and read live window or snapshot JSON (12 unread, 4 recent, 6000 UTF-16, `readThroughSeq`, partial metadata; rendering never marks read).

## Reserved2 admission, budgets and snapshots

- **Drivers (`live_bridge.rs`, `reserved2.rs`, `session::Driver`, `wake::WakeScheduler`):** `<=1` running turn/conv while ingress continues; completion coalesces base wakes after urgent-coverage checks; 500 ms finite-setting poll. Ingress resolves names/quotes, stores 200 UTF-16 `text`/`plain` + last 200 `tail` (triggers/slang use `plain`; empty plain without bot quote settles unstored; `@ID`/quote fallbacks; media/forwards preserved).
- **Access & suspension:** explicit allow required (deny prevails); hub checks access pre-pump/dispatch (`sync_wake_configs` skips denied); refused wakes clear scheduler + settle ingress without bootstrap/turn/notice. Engine admission checks pre-ledger. Pause/disabled `socialV2` cancels ordinary queued batches; suspension during claim keeps queued until resume.
- **Turn budget (`wake::turn_budget`):** dispatch cap `max(120000, observation + max_quiet + 5000 + 90000)` ms (default 515000 ms), collector `ceiling + 30000` ms (30.5 min; `socialV2.turnTimeoutSecs` does NOT bound reserved2). Ceiling `socialV2.wake.turnCeilingMs` (`wake::turn_ceiling_ms`): 1-2 h int ms (default 30 min, `>= cap` incl. legacy caps; console refuses invalid/`cap > ceiling`; invalid edit falls back), measured from dispatch or `engagedAt` (`>= dispatch`) while engaged. Hub freezes cap/ceiling (`WakeScheduler::turn_cap_at`). `observation` = `socialV2.wake.preSleepWaitMs` (default 300000 ms, truncates non-negative decimals; 0 if `preSleepWaitEnabled` false [default true] or 0; applies in private too). `max_quiet = max(wait.minQuietAfterNewMs, min(120000, wait.maxMs), validated wait.batchMaxMs)`. `socialV2.wake.turnHardCapMs` overrides cap (console refuses `< observation + max_quiet + 5000 + 30000` [455000 ms default], `>2 h`, non-int; reset restores derived cap; mixed edits commit with wait settings).
- **Deadline enforcement & observation sleep:** dispatch writes token-free `budget` ledger row (`deadline`, `capMs`, `ceiling`) pre-backend; waits extend deadline to `engagedAt + capMs <= ceiling`. Waits/observation/batching stop 20000 ms pre-deadline (`<1000 ms` useful wait returns `turnBudgetExhausted` with 0 observation credit); sends/reply holds/resumes ignore budget. Legacy turns infer from wake-claim/begun or `waitTurnDeadlineAt`. Hard cap landing in a live messages wait (`activeWait` holding one-use OS witness `locks/observation-wait-<hash>.lock`) stops adapter, revokes authority, and completes `observationSleep` (keeps wake config/unread, skips closure/no-action; stale marker grants no sleep; stop+revoke run even on bookkeeping fail).
- **Cancellation & epochs:** ingress/tick route `turnTimeout` via non-aborting cancel handler (never queued as wake); queued harness expiry checked post-admission & pre-publish (incl. pinned CLI), settling without dispatch/retry and consuming matching finite claim. Handler owns sole cancelled ledger end post-revocation (`sessions-recovery.md`), preserving prior completed end; minted cancel epoch adopted even if DSH stop failed (collector aborts `wake::COLLECTOR_HEADROOM_MS` post-cap -> cancelled). Abandon rotation holds shared epoch slot across persistence/publication; ingress/tick read under publication mutex (released pre-ledger write); completion adopts only current nonempty owned token; turn end drops own `turnTimeout`.
- **Epochs & closures:** absent/empty tokenless epochs equivalent until 1st token; changed nonempty tokens invalidate queued work. Ingress adopts changed wake config pre-batch; ticks keep batch. Closure consumes mark-read/set-wake-config; missing closure sends `<= maxWakeConfigReminders` (2 incl. original turn) without extra snapshot/counter/rate entry; exhaustion resets wake config (keeps `dropNames`, drops `keywords`). No-action completion checks model start/actions (default limit 3), keeps `keywords`/`dropNames`.
- **Snapshots & receipts:** authenticated console POST post-admission/replacement. DSH redacts chat fields pre-JSON + guidance separately; harness keeps raw packet for replay & redacts at delivery; keys/IDs/cursors preserved. Offered unread msgs earn process-local token-scoped receipts (each snapshot names turn & replaces prior grant incl. retry; console checks captured cap). Mark-read requires `throughSeq <= readThroughSeq` (wake-config may omit); admin can ack or `clearAll: true` without cursor; independent reads keep own receipts; restart/rotation void both (pre-admission harness cap attempts immediate rotation). `lastReadThroughSeq` persists (removes legacy disk receipts); only positive safe unread seqs advance cursors.
- **Mode transitions, timers & reminders:** revisions increment on real transitions (rotate tokens, settle ingress, retire mappings/policies, stop/archive DSH pre-publish; away-and-back invalidates; `preemptAfterMs` default 0). Busy timers queue without wake quota; completion rearms reply checks; limits cover message/finite/reply-check/proactive across restarts; proactive clears on pause/disable/revocation. `reminder:<id>` renders `【提醒内容】` pre-tail (delta/compat) and pre-`【输出要求】` (pinned CLI), showing `由你自己设置` for HER-created, flattening newlines, `【】`->`〔〕` (cancelled note if cancelled).

## First-generation reserved and chat/closed-agent modes

- **1st-gen reserved (`social-v1.json`):** 5s driver; `social.enabled=false` uses chat; `social-v1.json` gated & reset on startup. Partial config normalized/merged (`[0,1]` probs, nonnegative/swapped gaps); flush awaits silent completion (`reserved-summary`) and keeps failed summaries. Conversations in `reserved` run on DSH or the harness per conversation engine selection (`engine_switch`), reusing `chat` and owner-private `chat` harness profiles/prompts (`prompt.mode.chat`, `prompt.mode.ownerPrivate`) while bypassing DSH queuing/outage parking when no DSH handover is needed. Jobs recheck mode/gen/token pre-prep/DSH/harness submission/send; admin idle/reset/exit settles pre-HTTP 200 (stopping DSH sessions lazily only when open DSH turns exist; keeping live Gen-1 harness turns attached on mode exit so `check_harness_turn` + `turn.wait().await` settle SQLite/ledger without premature `ended`). Pending jobs/flushes refresh tokens across valid `engine_switch` rotations via `Handover.prior_epochs`. Unsubmitted retries `<=3`; unknown uses turn recovery. Face norm before burst split (1000/8000 ms zero-gap fallback); timestamps advance on whole-burst success; manual active excludes buffered input.
- **Chat mode:** allow/deny (`deny > allow incl. aliases > allowAllWhenEmpty`), drop own echoes; silent role -> owner slash -> model. Owner whole-msg ASCII case-insensitive commands: `/reset`, `/new`, `/status`, `/silent`, `/quiet`, `/active`, `/speak`, `/role [<name>|off|clear]` (`角色卡已停用：请用 /persona 或控制台的人设页切换人设。` in companion modes). Embedded/other owner `/` -> model/DSH. Non-owner `/` silently ignored (handled) in chat/reserved (except `/update` refusals); non-owner DSH `command` logged & dropped. Preset `qq-chat`; 1 worker/conv. DSH acks once -> renames group -> final reply (4000 UTF-16 parts via outbox; `[SILENT]`/empty/send-tool/sentinel/silence suppresses; abort says stopped; error alerts owner metadata-only; `command.text` via sentinel; mode POST sets `dshSynced`).
- **Admin private `/update`, `/update deps`, `/persona`:** whole-msg ASCII case-insensitive pre-mode dispatch; groups/non-admins get fixed refusals (`/persona`: `人设只能由管理员在私聊或控制台切换。`). `/update` confirms versions via recorded QQ send before approval, holds turn admission through reply/approval/handled write, refuses concurrent install/restore/handover, reloads owner under config gate. `/update deps` approves 1st displayed change (SnowLuma then DSH) post-confirmed report; discovery via supervisor/console only (`docs/agents/lifecycle-tasks.md`). `/persona`, `/persona <name>`, `/persona <name|off> <conv>` (`<=3` words) lists/assigns via recorded send, rechecks admin under config gate, names failed re-brief convs; closed-agent replies `closed-agent 模式不使用人设，人设未改变。` (no turn admission).
- **Closed-agent mode:** owner private only; preset `closedAgentPreset` -> DSH default -> marked default (unresolved empty omitted). Settings refresh 5s; policy changes retire mappings/tokens; receipt serialized with mode writes (45s live, 0 maintenance).

## Interactions and approvals

- **DSH (`pending-interactions.json`, cleared on start):** 10s WS handshake; reap skips busy state; stream sequential. Lock order: pending state -> interaction gate -> send chain (release gate between retries; question deadline bounds). All-undelivered removes request + saves snapshot, releases pending state, submits empty answer/rejection on 30s blocking worker; confirmed/uncertain keeps open (never auto-resent). Owner only (case-insensitive label or custom text; `questionTimeoutMs` 5m). Collector tries gate once/check.
- **Harness `ask_owner` (`pending-owner-interaction.json`, cleared on start):** 1 question `<=280` UTF-16, `<=4` distinct options `<=48` UTF-16; owner replies label or `<=2000` chars. Mailbox settles 1st valid private reply pre-expiry even on deadline/cancel wake; `/reset`/`/new` bypass; `questionTimeoutMs` 5m capped by remaining turn; 1 closure notice on expiry satisfies failure notice.
- **Group approval:** `/approve <id>` or `/deny <id>` in owner private only (stray reports nothing pending).

## Model text redaction, prompt text and upstream capture

- **Blacklist & `model_view`:** `socialV2.context.stripFromModelText` merges with `config/model-text-blacklist.json` (`<=64 KiB`, `<=500` entries, `<=64` chars/literal; failure state in `data/model-text-blacklist.state` under `locks/model-text-blacklist.lock`, 1 warn/transition). `model_view` replaces literals case-sensitively with `【已隐藏】` (indivisible; skips if boundary exposes denied term; keeps JSON/IDs/cursors/tokens/media/numbering; echoes filter pre-escape; logs/console/outbound keep originals).
- **`model_text_policy` & `prompt_text.rs`:** `model_text_policy::denied_terms` blocks harness/model/platform/developer/layout/AI/robot/assistant on rendered surfaces (`console::tests::model_text_guard_tests`), prompt text, history summaries (`harness.md`), DSH guard (`mcp-memory.md`), and upstream sweep. `prompt_text.rs` (`prompt.{notAClerk,proactive,groupConduct,repeat,stickerStrategy,stickerSoften}`, `prompt.mode.*`, never `chat`, hot-read) validates `<=2000` scalars (mode `8000`), LF/tab, no runtime harness/endpoint key, no `denied_terms` (stripped invisible format chars + word-boundary + folded uppercase + as-written), falling back audit -> file -> compiled default.
- **`her-cli upstream-capture` (`upstream_capture.rs`):** `arm --runtime-root <root> --route dsh|harness [--minutes 1-1440]` (default 30, `data/upstream-capture/armed.json`, survives restart). Non-blocking snapshot -> detached thread atomic claim -> `captured.json` (>16 MiB size-only; errors in `last-failure.json`). `sweep` prints counts + structural JSON paths (`<key>` masked, base64 >=256B skipped) and deletes capture (`capture file invalid` on bad shape). `status`/`disarm`; excluded from backups/vault/repo; arming prod is owner-only (`production-ops.md`).

## Wait batching and turn allowance

- **`socialV2.wait.*`:** `batchWindowMs` (8000) / `batchMaxMs` (30000; 1-120000 int ms; owner/@ returns immediately; stores `atSelf`/`isOwner`). `maxPerTurn` (default 4) shared across wait/reply under social gate per turn+epoch (final slot forces full observation -> `waitLimitReached=true`, `nextAction="end_turn"`, `"end this turn now: produce your final answer and make no further tool calls"`, completing as `observationSleep` with wake config kept).
- **Engagement & `forYou` (`question::ingress_for_you`):** `engagedAt` (cleared at claim; set by delivered text/voice/sticker/poke; applies in private too). Agent messages wait runs to window end (clipped by `wait.maxMs` unless forced observation exceeds it, and turn budget), returning immediately on `forYou`/urgent @/owner, else collecting chatter -> `engagementEnded=true`, `preSleepWaitSatisfied=true`, `turnBudgetEnded`, `observationSleep` (`<1000 ms` hands over waiting `forYou`/urgent or ends immediately with chatter). Urgent/`forYou` anywhere in result write never ends turn (1 step, no refund, next wait refused). `forYou` (`私聊你`, `拍了拍你`, group quote/@/nickname/card/exchange) refunds slot `<= socialV2.send.maxPerTurn` (20) times/turn; `【互动窗口】` shown while active.

## Cache-aware session rotation

- **DSH (`session_rotation.rs`):** rotates idle sleeping DSH convs when last call total input >= `dsh.rotation.caps` (fallback `default`, else 500000) and `max(0, dsh.cacheTtlMinutes - 1m)` elapsed (`local-relay` 5, `opencode-go` 120) with confirmed wake config and no active/queued/compaction/CLI blocker. ## Harness idle rotation

- **Harness (`harness/rotation.rs`):** `due_at(cfg, last, idle_from)` checks `harness::store::last_call` (`captured_usage.prompt_tokens > 0` + route id) against `harness.cacheTtlMinutes` (no built-in default; DSH settings never apply) and `harness.rotation.caps` (else `default` else 500000), rotating in place with 4000-token handover (`docs/agents/harness.md` "History budget and checkpoints").

## Bridge-enforced reply timing

- **Suppression & `question.rs`:** running turns suppress non-urgent wakes (`in-turn`); urgent @/owner drops (`covered`) only on exact seq in turn's successful tool response post-writes (no CLI/snapshot/cursor coverage). `triggers.question` admits quote-to-her or exchange participant within `questionExchangeWindowMs` (90000 ms, excluding `@`ing others; nagging needs exchange; failed/uncertain sends create no exchange).
- **Debounce, quiet & typing holds:** `reply.wakeQuietMs` (3000, 1-30000; substantive resets <=30000 ms, owner/@ immediate). Pre-bubble & pre-outbox: log-normal quiet (sigma 0.5, `[4000, 25000]` median `10000` ms; urgent `1000/3000/6000`; overrides 1-120000, `min <= median <= max`) from `lastReplyIncomingAt`, overlapped (max) with typing budget (`* [0.75, 1.25]`, seedable RNG, credited by DSH/harness thinking). Private holds send best-effort `set_input_status` 1/0 (250 ms). `inbound_text::quiet_neutral` (media/emoji-only incl. `[图片]`/`[表情…]`/CQ) skips `lastReplyIncomingAt` extension while still triggering held revisions.
- **Revisions & limits:** arrival during hold cancels unsent bubbles pre-outbox -> HTTP 200 `{held:true, reviseRequired:true, sent, newMessages, receipt/cursor, "对方又说了…"}` (max 3/turn-epoch `replyRevisionBudget`; 1 atomic `superseded` record covers remaining indices or 503). `hf119_reply_prompt_leaves_timing_to_the_bridge` tests `her/tests/fixtures/qq-chat-v2-reply-timing.yml`. `mergeMultiIntoOne` (true), `burstEnabled`, `maxMessageChars`, `burstMaxMessages`, minute/hour quotas (8/60, cap 500), `repeatLimit` (2), `maxPerTurn` (20), `repeatWindowSends` (0) -> HTTP 429 + <=1 content-free owner notice/turn (`media-transport.md` face norm).
- **Reserved2 CLI relay:** companion console required (1s connect+write, 300s total; transport fail logs `CLI reply send failed: companion console unavailable`); retains turn token, audits canonical text, cumulative new-message packets (<=3 revisions), 429 ends without DSH fallback, `[SILENT]`/empty revised ends clean (`dependency-recovery.md`).
