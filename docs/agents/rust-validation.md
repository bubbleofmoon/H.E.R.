# Rust build and validation

## Every host

- **Binaries (`her/Cargo.toml`):** `her` (Windows GUI) and `her-cli` (console) share `her/src/entry.rs`; `herupdate` uses `her/src/updater.rs`. `unit` -> `--bin her`, `herupdate` -> `--bin herupdate`, integration -> `--test <target>` (never `--lib`). `her_binaries` checks PE headers and app/CLI dispatch.
- **Build & features:** CI compiles/lints/formats/tests; native checks build offline in a build slot with isolated `CARGO_TARGET_DIR`. `release_install` requires `--features parity-clock,release-test-keys`; `release-test-keys` is rejected in release/optimized/no-debug-assertions builds. Local `rustfmt` and `fmt-patch` hunks apply only to owned files.
- **Fixture isolation:** unit runtime tests use `runtime::tests::runtime_fixture` (keep guard alive). Set `HER_INSTALL_ROOT` to unused temp boundary and `HER_TEST_CLI` to built `her-cli`; guard temp roots and evidence paths (`TICKET13_EVIDENCE`, `TICKET15_EVIDENCE`, `TICKET19_MEDIA_EVIDENCE`, etc.) before mutation; package `scripts/lifecycle/fixture-paths.ps1` beside copied observers. Never use real tokens/services or run legacy `check-all`. Classify setup errors honestly (not compile/product failures; SKIP/`--no-run`/startup failure are not passes).
- **Parity & determinism:** compare console/live timestamps via shared host clock + `HER_PARITY_RANDOM_SEED` (unless `HER_PARITY_ADVANCE_FILE` is used with fixed epoch). Wait for observable state completion (cancel RPC before rotation, tool send before collector ledger writes, `/api/pending` with bounded deadline after `$events/result`, held reconnect handshake until expiry).
  - `supervisor_dependencies` waits for exec out of inherited test image before recording cleanup identity. Dependency-upgrade crash fixtures use confined `data/lifecycle/dependency-upgrade-pause` + `dependency-upgrade-reached` (<=30s). Portable handover fixtures bound child exit + capture-pipe EOF; outage fixtures use disposable file scheduler + online login status.
  - `console_runtime_routes` QQ login test runs with `--features parity-clock` or host clock (asserting >=60s between attempts incl. 45s quiet restart and 30s polls). Fix compile errors directly; rejected auto-review/guard patches did not apply; planners never build.

## Linux host (`/root/her`)

- 4 cores / 7 GB RAM, 1 build slot: run gated native checks only via `scripts/cargo-slot.sh <ticket> <worktree> <evidence-dir> <run-name> <cargo subcommand> [args...]` (`--offline -j 2`, `nice -n 10`, `CARGO_TARGET_DIR=/root/rb-targets/<ticket>`, `RUSTC_WRAPPER=sccache`, `CARGO_INCREMENTAL=0`, `opt-level=2` deps; `test`/`run` release build slot into `QQBOT_TEST_SLOTS` default 3; 60s `owner.txt` heartbeat, 300s stale break; never touch locks manually).
- Set `HER_GITLEAKS=/root/.cache/her-gitleaks/gitleaks` (`install-gitleaks.py`, else exit 3 `scanner-missing`). Run `--test <target> -- --test-threads=1` (`session_turn_recovery_e2e` and `release_install` need `--features parity-clock`; unwritable ledger uses `chattr +i`). Optional `rustfmt`: `/root/.cargo/bin/rustfmt`.

## Windows host (clone `C:/her`)

- **Shell gotchas:** in Git Bash use `MSYS_NO_PATHCONV=1` for `git show <rev>:<path>`; avoid inline `python -c` backslash literals (`scripts/check-repo.py` catches control chars, `--eol-base <rev>` checks LF/CRLF parity). In PowerShell 5.1, use `git grep` (not `rg`), `; if ($LASTEXITCODE -ne 0) { exit $LASTEXITCODE }` (not `&&`), run `gh-public.ps1 pr create` inside the branch worktree without `--base`/`--head`, `-like` / `[regex]::Escape` for path matches, write UTF-8 files without BOM via `[IO.File]::WriteAllText($p, $text, [Text.UTF8Encoding]::new($false))` (never `Set-Content`/`Add-Content`/`Out-File -Encoding UTF8`; enforced by `scripts/lifecycle/test-ps-count.ps1`), and `-File` for non-trivial scripts. Smoke-test release binaries with `install-root layout` rather than `--help`.
- **Throwaway `HER_INSTALL_ROOT` rehearsals:** keep `HER_TASK_SCHEDULER_FILE` outside `HER_INSTALL_ROOT` (`FileScheduler` uses `check_development_path`), and set `backends.mcpRustBridge: true` when `watchdog` should start `--console-serve`.
- **Layout:** `C:/her` (integration), `C:/her-wt/<ticket>`, `C:/her-orch`, `C:/her-targets/<ticket>`. Production `C:/qqbot` (plus archived pre-move folders until #127) is read-only.
- **`scripts/cargo-slot.ps1`:** `scripts/cargo-slot.ps1 <ticket> <worktree> <evidence-dir> <run-name> "<cargo subcommand> [args...]" [-ExpectFail]` (coordinator runs `C:/her/scripts/cargo-slot.ps1 -WorkTree <worktree>`; stale copy writes `.stale-slot-script.txt`; `-ExpectFail` enforces non-zero exit on TDD red receipts). Sets MSVC, runs `$env:USERPROFILE\.cargo\bin` `+stable-x86_64-pc-windows-msvc ... --offline -j 2` (`QQBOT_CARGO_JOBS`) hidden into `C:/her-targets/<ticket>`, writing `.stdout.log`, `.stderr.log`, `.exit.txt` (`.build.log` for `test`/`run`). Build slots (`build-slot.lock`, `build-slot-2.lock`, CPUs 0-3 BelowNormal) release before test slots (`test-slot.lock` CPUs 4-7 Normal, `test-slot-2.lock` CPUs 0-3 Normal; `.slot.txt` records mask; overrides `QQBOT_BUILD_SLOTS`/`TEST_SLOTS`/`*_CPUS`). Timeouts: `QQBOT_TEST_TIMEOUT_MIN` (60), `QQBOT_BUILD_TIMEOUT_MIN` (90) -> exit 124 + `.timeout.txt`. Never touch locks manually.
- **Target disk & pruning:** checks `HER_TARGET_ROOT` drive pre-Cargo against `QQBOT_MIN_FREE_GB` (40 GiB); if low, prunes targets older than `QQBOT_TARGET_MAX_AGE_DAYS` (2d) oldest-first until min + 20 GiB headroom (protects current ticket + active `owner.txt` PIDs; skips reparse points/junctions; logs `.prune.txt`). Still low or unverifiable -> exit 123 + `.disk.txt`. Test disk guard only with throwaway `HER_TARGET_ROOT` + lock overrides + high threshold.
- **gitleaks & runner hygiene:** `scan-public.py` auto-discovers `C:/her-orch/tools/gitleaks-*/gitleaks.exe` when `HER_GITLEAKS` is unset (`HER_GITLEAKS=C:/her-orch/tools/gitleaks-8.30.0/gitleaks.exe`; missing override exits 3). Launch hidden runners via `Start-Process -WindowStyle Hidden -PassThru`, cache `$null = $process.Handle` immediately, set `.PriorityClass = BelowNormal`, never assign `$PID`, create dirs via `[IO.Directory]::CreateDirectory()`. Align runner `USERNAME` to `[Security.Principal.WindowsIdentity]::GetCurrent().Name.Split('\')[-1]` before native ACL tests.
- **Targets & native runners:** run integration targets `-- --test-threads=1` (`session_turn_recovery_e2e`, `dependency_recovery_e2e`, `release_install` need `--features parity-clock`). Handover/fault parity vars (`HER_TEST_HANDOVER_CONTROL`, `HER_TEST_UPDATE_PLATFORM`) must stay outside install root and be unset for native checks.
  - `powershell.exe -NoProfile -File scripts/lifecycle/test-external-path.ps1` (path regressions), `scripts/lifecycle/test-ps-count.ps1` (PS 5.1 static lint).
  - Shut down test runtimes with `shutdown_timeout` before dropping fixture roots (`os error 32`). `health_check` reconcile case uses `check_bounded` (~7s native startup).
  - `scheduled_task`: `HER_TASK_SCHEDULER_FILE` for normal runs; elevated round trip uses GUID `HER-Test-*` without trigger.
  - Proof runners: `scripts/lifecycle/test-release-proof.py <candidate.exe> <installed-dsh-support-root> <evidence-dir> [--highest]` (elevated AC3 `--highest` records `execution-context.json` + `artifacts/task-principal.json`; non-elevated exits 2) and `test-release-chains.py`; timeout tests `test-release-timeout.py` (124 timeout / 125 launch fail).
  - Move rehearsal (#67): `scripts/lifecycle/test-production-move.ps1 -Candidate <dir> -NodePath <node.exe> -FixtureRoot <new %TEMP% dir>` (`HER-Test-67-<guid>` fixture tasks, ends `PASS production move rehearsal`).
  - `supervisor_dependencies`: `--features parity-clock` + `HER_TEST_DEPENDENCY_CLOCK=1` (`data/lifecycle/dependency-clock`); VM_READ-denied fake models inaccessible process.

## GitHub-hosted CI (the merge gate)

- **`.github/workflows/checks.yml`:** `changes` (`code=true|false`) -> `scans` (Windows+Linux `scripts/ci/run-scans.py` + `scan-public.py` w/ gitleaks + Windows `scripts/lifecycle/test-ps-count.ps1`) -> when `code=true`: `ui-build` (`HER_REQUIRE_UI_DIST=1`, uploads `her-ui-dist`), `lint` (report-only), 5 Linux `tests` shards, `dsh-contract` (Ubuntu 22.04), and 5 `tests-windows` shards on `main` pushes only -> `checks-gate` (gates PRs and `main`). Hosted passes are never rerun locally; local gates run Windows-native/elevated/scheduler/ACL/release-proof/hotfix checks only. Fork PRs need approval; never attach self-hosted runners.
- **`dsh-contract`:** tests all versions in `her/dsh-contract-versions.txt` (`<version> <sha512>`) inside isolated Linux user/net/PID namespaces (`python3 -I scripts/ci/dsh-contract.py [--version <v>]`; quick target `dsh_contract`).
- **`scripts/ci/run-tests.py`:** `--shard K/5`, `--only NAMES`, `--filter TEST`, `--known-red scripts/ci/known-red.txt` (shard timings in `scripts/ci/ci_suite.py`; `release_install` passes `--features parity-clock,release-test-keys`; `memory_library` runs `her-memory`; `scripts` target runs `scripts/ci/run-script-tests.py` covering every `scripts/lifecycle/test-*.py` not in exempt list).
- **`known-red.txt`:** `<os> <target> <test> #<ticket>` (`linux|windows|any`; coordinator-only; matches exit 101 + exact failure count + listed tests; PR body lists additions).
- **`.github/workflows/quick.yml`:** `workflow_dispatch` (`target`, `filter`, `os`, `sha` ancestor check; split Windows batches <=45m; `check` and `lint` run separately; `lint` uploads `fmt-patch` and `clippy-fix-patch` — inspect `clippy --fix exit` before applying partial hunks).

## Crate contracts

Fixtures use `tests/fixtures/`, `../scripts/` fakes (no JS bridge/`memory/`), and `tests/support/mod.rs` (`support::ports::reserve()` -> `into_listener()`, `ports::start_console`, `Reserved::release()`, `ports::hold`/`release_held()`, `ports::OwnedChild`, `FakeGateway`, `RuntimeRoot`, `write_dependencies`, `hide_window`; `support/selftest.rs` via `config_runtime`; never bind-and-drop port 0). `tests/support/console.rs` handles console startup retries (<=3 ports) and drop cleanup. With `parity-clock`, `HER_PARITY_ADVANCE_FILE` advances fixed epochs on rename after witnessing active locks/responses; `rbridge-live`/DSH phase ring keeps latest 128 entries for failure dumps. Parallel wait fixtures use distinct conversation keys.
