# Runtime paths and configuration

Read for runtime selection, configuration, settings store/registry, file ownership or process/ACL boundaries.

## Install root and `RuntimeContext`

- **`install_root.rs`:** `--install-root` / `HER_INSTALL_ROOT` (one only; default `C:/qqbot` Windows, `/qqbot` elsewhere). `her-cli install-root layout` prints `herupdate.exe`, `current`, `last-good`, `releases`, `deps/{snowluma,dsh,relay}`, `runtime`, `runtime/user/dsh`, `runtime/dsh/work`, `runtime/data/logs`, `backups`. Production path spellings (`C:/qqbot`, `qqbot-rust`, `legacy_path!`, profile `.dsh`) live only in `install_root.rs` (`tests/install_root.rs` enforces unless `// layout-literal: <reason>`).
- **Guards:** supervisor/commands targeting install root require OS executable under `<install>/releases`; `RuntimeContext` rechecks post-canonicalization (redirected ancestors into install root refuse). Dev/test roots outside install root call `her-cli install-root check-development --runtime-root <path>` (0 allowed, 2 refused; `HER_TEST_CLI` selects CLI; guard temp roots + evidence paths before mutation). Launchers call `check-supervisor --runtime-root <path> --executable <resident>` (read-only). `dsh-mcp-config` and diagnostic/probe modes are dev-only even via installed CLI (exception: `#67` move script on private copy with decoy `--install-root`).
- **Releases & handover:** `release install` requires OS image under `<install>/releases`, `runtime/data/locks/update-restore.lock`, no symlinks/junctions, create-new staging. Trust derives from verified current signed version/key set (fallback: newest verified `last-good`/previous link -> newest verified installed release; compiled pins bootstrap only when no versioned release/selection links exist; pre-v0.1.0 unsupported; `docs/agents/lifecycle-tasks.md`). Handover runs `<install>/herupdate.exe` from install root; `current`/`last-good` swap via prepared sibling link + atomic rename.
- **`RuntimeContext` confinement:** rejects traversal, symlinks, junctions, reparse points, redirected ancestors (Windows transient `$Extend\$Deleted` `ERROR_DELETE_PENDING` -> `path/canonicalize` refusal). `dsh`/`onebot`/optional `onebot_ws`/`relay` must be explicit literal loopback (`loopback_http.rs`); `model` accepts literal loopback HTTP or clean HTTPS OpenAI-compatible base URL (`/v1` appended only to bare origins). `voiceTranscription.helper` lives in `config.json` (loopback IP origin, `docs/agents/media-transport.md`).
  - CLI modes: services require `--runtime-root` or `HER_RUNTIME_ROOT` (exit 2); subcommands (`backup [restore]`, `console`, `conversation`, `dsh-mcp-config`) require `--runtime-root`; `install-root layout` needs none. JSON loaders accept UTF-8 BOM.
- **Config loading & rollout:** `load_config_document` reads `config.json` + `overlay_config`; `load_config` normalizes; `load_config_requiring_settings` (`settings::overlay_checked`) fails on store errors. `RuntimeContext::config_stamp` caches file-only values (never registry settings; console whitelist also checks `settings::store_mark`). `rollout.rustGroups` requires explicit JSON array of canonical keys (matches `--live-groups`; empty = no live owner).

## Live settings store and registry (`settings.rs`)

- **Store (`data/settings.db`, `settings/store.rs`):** WAL, `synchronous=FULL`, `busy_timeout` 5s, no-follow open; `locks/settings-store.lock` (5s wait -> 503) held from pre-open inspection through close on all writers (readers skip gate, use 100 ms `busy_timeout`, retry transient sidecars/`delete-pending`/`SQLITE_PROTOCOL`/WAL-close up to 5s `WAL_SWITCH_WAIT`, `online_snapshot` 30s). `user_version` 1 (global+audit), 2 (+conversation settings), 3 (+console auth). Every file (`settings.db*`, lock) must be plain 1-link or absent; exact `sqlite_master` schema required; hot leftover `-journal` refuses (readers `storeError`, writers 503).
- **Registry (`settings/registry/`, `settings/kinds/`):** defines key, pointer, `SettingKind`, default, applies, group, label, hint, `chat` (`docs/agents/mcp-memory.md`). Kinds: integer range (clamp/default), optional integer (`null` fallback), model id (trimmed 1-200 non-control), model-visible text (`<=N` scalars, LF/tab, no `denied_terms`), bounded number, route tokens (`[1000, 10_000_000]`), probability (`[0,1]`), switch (`false` = off), id list (`<=10000` positive safe ints / no-leading-zero strings; `allow.group` aliases), owner id (`null` default), daily time (`HH:MM`), zone (`host` | IANA), route id (`1-64` `[A-Za-z0-9._-] != default`).
- **Overlay, writers & write-back:** overlay reads store (never creates), falling back on refused text to newest passing audit row -> file -> default (1 stderr warning/key/process). Writers: console settings/page saves (`settings::console_changes`, `config_tx::commit_page_config`, `settings::apply_changes`, `ConfigDiff`), chat settings tools.
  - `settings::apply` / `reset` / `undo` / `history` (100/page) run in `IMMEDIATE` tx; revisions strictly monotonic; `undo` refuses scrubbed/credential-bearing `harness.apiBaseUrl` entries with 400 (checked before `409` `migration`) and refuses credential/secret entries, `migration` rows, non-latest rows, changed stored values, or invalid old values with 409 (removing stored value deletes from `config.json` too, 503 on failure); `keep_registry_values` & `afterRegistryFreeSha` (`settings::registry_free`) preserve registry values on console audit undo.
  - Seeding copies eligible unseeded global settings from `config.json` (`system`/`migration`, rev 1) after saving `config/config.json.pre-settings` byte-for-byte if missing (503 if unreadable). `settings::write_back` mirrors stored values into `config.json` post-store-gate under `config_gate` (failed mirror sets `mirrorError` and finishes at next write/console start). `config_tx::write_selected_config_text` refuses direct edits to ordinary registry members (`<key> changes only through the settings store`).
- **Lock hierarchy:** `locks/restore-writers.lock` (shared for unstopped `memory.db` / chat-tool writers; exclusive for restore) -> `credential_mutation_gate` -> `task`/`closed_agent` gate -> `config_gate` -> `transport_authority` -> `store_gate` (nothing waits while holding `store_gate`; write-back runs after `store_gate` under `config_gate`).
- **Security settings (`settings/registry/access.rs`):** `allow.{private,groups}`, `deny.{private,groups}`, `ownerQQ`, `security.{interceptNotify,outboundGuard,requirePasswordLocally}`, `rollout.rustGroups` (none chat-writable; require `"confirm": true` / `--confirm` -> 409/400). Access changes run via `config_tx::commit_access_setting_change` (closed-agent gate -> finish pending revocations -> `config_gate` -> `settings::preview` -> store write -> revoke). Security settings (excl. rollout) seed only when changed themselves (refusing unstoreable `config.json` lists with 409). `rollout` seeds only when valid and within effective allow lists (`undo` 409 on gap).
- **Endpoint credentials & `harness.routes` (`#443`):** `harness.routes` seeds valid lists (`id`/`model` checked for leaked endpoint keys). `webSearch.apiKey` binds to HTTPS search URL; `cliModel.apiKey` and `harness.apiKey` bind to canonical `E` (`settings::resolve_model_endpoint_and_key`: `settings.db` `harness.apiBaseUrl` [JSON `null` = unset, non-null malformed fails closed] -> `config.json` -> `dependencies.json` `"model"` `D`; `--live` sees UI edits immediately, `dependencies.json` needs restart). Old `[bound, key]` rows persist across `A -> B -> A`. `harness.apiKey` falls back to `config/harness-api-key` only when `canonical(E) == canonical(D)` (`config.json` `/harness/apiKey` ignored/unmirrored). `reject_credential_text` guards prompt text & `harness.apiBaseUrl` (plus stored keys in `harness.routes`) across `store`/`undo`/`apply_changes`/`seed`; credential-bearing `harness.apiBaseUrl` is suppressed across resolution, `/api/settings*` and restore previews.
- **Per-conversation settings (`settings/store/conversation.rs`, schema >=2):** `conversation.engine` (`dsh`|`harness`, fallback `engine.default`; CLI pin overridden only by explicit stored `harness`) and `conversation.route` (fallback `harness.firstRoute`; reset stores JSON `null` [`configured order`] overriding `harness.firstRoute` rather than inheriting it; read lock-free via `settings::conversation_value`). Keyed by canonical key (`group:<id>`/`private:<id>`); outside overlay/write-back; legacy `conversationEngines` imported idempotently in 1 tx. Access changes clear unadmitted conversations' scoped settings atomically (`actor: system`, `source: access`, un-undoable).

## Credentials, ACLs and filesystem guards

- **Config & tokens (`config.rs`):** `simulation` -> `reserved2`; machine auth uses configured `consoleToken` or OS-random `data/console-token` (owner-protected). Rotation holds `credential_mutation_gate` -> `config_gate`, revokes browser sessions, writes `data/console-token-rotation`, publishes token file then config.
- **Desktop grants & admin password (`console_auth.rs`, `console_auth/storage.rs`):** `data/console-desktop-grants` (<=128 grants, 12h, issuer PID/start bound, cleared on full restore/rollback). `console.administratorPassword` stored in `settings.db` as Argon2id v19 PHC (16B salt, 19 MiB, 2 iter, 1 lane; masked `(hidden)` audit; lock order `credential_mutation_gate -> config_gate -> browser_anchors -> store_gate` with Argon2id outside). `her-cli console set-password|reset-password` takes `data/locks/console-credential.lock` (8-1024 scalars, 8 KiB/line redirected stdin, exit 2/3; `reset-password` clears browser sessions/throttle and advances `auth_generation` via SQLite secure deletion; concurrent full restore -> exit 3). `data/console-auth-generation` tracks destination restore generation (excluded from backups/archives).
- **Boundaries & guards:** `subprocess::external_path` converts verbatim paths for child/PS/MCP boundaries. `her`/`her-cli`/`herupdate` clear `HANDLE_FLAG_INHERIT` on incoming Windows stdio handles at entry (non-panicking stderr diagnostic on failure).
  - `guarded_file.rs` (Layer-0, `herupdate`-safe per ADR 0003): no-follow reads, plain-ancestor/link checks, sibling temp + fsync + `MoveFileExW` write-through (1s OS 5/32/33 retry; `RuntimeContext::rename_file` 500 ms), 0600 gates, path-class errors without secrets/paths.
  - `guarded_fs.rs` (Layer-1): handle-based `ensure_entry_private` (`AlreadyPrivate` | `Hardened`), `AclPolicy::{OwnerOnly, OwnerSystemAdmins}` (Windows SIDs for user/SYSTEM/Admins; `settings.db*` hardened without `icacls`). `her/build.ps1` writes candidate dirs only.

## Crate contracts

Every executable clears inheritance on incoming Windows standard handles pre-threads/children (non-panicking diagnostic on error; explicit child stdio preserved). Nonblocking loopback fixture listeners must explicitly set accepted streams blocking pre-timeout; fixtures keep child guards, check locks post-release, witness durable admission pre-drop, and compile Windows curl fakes from fixture dir.
