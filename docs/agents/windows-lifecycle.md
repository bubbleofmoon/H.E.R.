# Windows lifecycle entry points

## Desktop app, login bar and tray

- **Entry & Run registration:** `her.exe` (or `app`) opens WebView2 console + tray (`--hidden` = tray only; installed defaults to `<install>/runtime` inferred from verified release image; dev requires `app --runtime-root <abs>`; WebView2 profile under selected `data/desktop-webview2`; loopback navigation only; hourly session renewal; close hides, tray Quit exits client).
  - Installed launch registers `HKCU\Software\Microsoft\Windows\CurrentVersion\Run\HERDesktop` -> `current/her.exe app --hidden` (cmd <=260 UTF-16 pre-write). `app --register-logon` registers and exits (installed images only); `--run-store <data-rel>` redirects to confined atomic JSON store (installed `app --run-store <file>` registers there and continues to UI for throwaway tray checks). Dev never writes real Run.
- **QQ login polling:** 30s authenticated `GET /api/qq/login` (even on QQ health fail). **QQ needs login** shows in window/banner/tray only when connected injected SnowLuma hook has `loggedIn:false,status:"loaded"` (`online:false` alone or contradictory/mixed state = unknown; `online:true` or consistent WebUI `loggedIn:true,status:"online"` confirms). Action refreshes route, checks PID/start vs native QQ image, and foregrounds/restores visible window (no QR/start/stop/inject/capture). Raises native tray balloon once per episode (latched across unknown/repeat until confirmed login; replayed across WebView nav; release smoke proves native balloon/focus).
- **`snowluma.webuiUrl`:** explicit HTTP literal-loopback + nonzero port; bearer token provisioned separately in `data/snowluma-webui-token` (never OneBot `accessToken`). Calls `GET /api/processes` only (no login/refresh/discovery; missing/expired creds -> unknown). OneBot supplies `get_status`.
- **Health & portable updates:** polls `lifecycle assert-running` JSON every 30s via hidden child (`current/her-cli.exe` or same-dir twin; 10s wait -> kill via retained handle + unknown). Verifies server Windows user on cred send. Tray Restart -> `/api/restart`. Tray polls `GET /api/releases` on same cycle; enables approval only for newer valid offered tag -> `POST /api/releases/approve` with confirmation (never direct install/handover; native menu/tray in `docs/release-smoke.md`).

## Launchers, PowerShell and lifecycle scripts

- **PowerShell 5.1 rules (`scripts/lifecycle/test-ps-count.ps1`):** wrap pipeline/command counts in `@(...)`; `Get-Content -Raw` keeps char length; cache `$null = $p.Handle` immediately after async `Start-Process -PassThru` when `ExitCode` is read (`-Wait` retains handle).
- **Paths & twins:** `external-path.ps1` (beside root launchers) and `subprocess::external_path` normalize verbatim drive/UNC paths at boundaries while keeping canonical paths for identity/containment (device/ambiguous/long-path-opt-in refused). Scripts use `her-cli.exe` for captured CLI and `her.exe supervise` for resident start (pipe GUI calls to `Out-String`/`Out-Null` so PowerShell waits; `her_binaries` checks PE images + stop script).
- **Supervisor task & manual start:** `her-cli install` registers `HER` running `current/her.exe supervise` (old VBS/PS/XML removed). Manual start: `Start-Process -FilePath 'C:\qqbot\current\her.exe' -ArgumentList 'supervise --runtime-root C:\qqbot\runtime' -WindowStyle Hidden` (quote spaces inside `-ArgumentList`). Supervisor starts/adopts dependencies and runs digest in Rust (`docs/agents/lifecycle-tasks.md`).
- **`restart-dsh.ps1`:** explicit paths + confirmation, reads loopback DSH port from `dependencies.json`, classifies Node entry under held handle and rechecks pinned identity pre-stop (npx matches resolved Node entry only; defers up to 30s for unresolved wrapper; foreign entries ignored unless holding selected port). Resets sessions via `lifecycle reset-sessions` on stopped runtime and resumes only if stop revision is still current.
- **Stop & fixtures:** `her-cli stop --runtime-root <root> --confirm [--with-dependencies]`. `scripts/lifecycle/test-lifecycle-fixture.ps1` takes explicit candidate, Node exe and new temp root, registers unique GUID fixture task, uses fake loopback residents, and samples process tree (`-RunLevelHighest` / `test-release-proof.py --highest` requires elevation; default Limited; 250 ms sampling limit). Retain DSH scripts/patches/fixtures until #13 retires DSH (ADR 0006).

## Crate contracts

`qq_login.rs` owns read-only SnowLuma probes and persisted supervisor episode claims (notified only on confirmed delivery; route hides account IDs/creds). Native desktop sign-in proves protected token file access via raw TCP without browser markers; browser-marked sign-in enforces canonical Host, exact Origin, Fetch Metadata, JSON, and live browser grant; both verify installing Windows TCP peer and recheck proof under config gate pre-bearer publish. WebView navigates to IPv4 loopback URL with its bearer; supervisor shares grant registry for deferred restarts.
