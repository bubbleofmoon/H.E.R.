# Third-party dependency notices

## Local recall dependencies

HER uses sqlite-vec for cosine distance in bundled SQLite and fastembed, ort and tokenizers for local CPU inference. ONNX Runtime is loaded separately at runtime. Xenova's ONNX conversion uses BAAI's MIT-licensed bge-small-zh-v1.5 model.

- [ONNX Runtime license](https://github.com/microsoft/onnxruntime/blob/main/LICENSE)
- [BAAI model card](https://huggingface.co/BAAI/bge-small-zh-v1.5)
- [Xenova ONNX model card](https://huggingface.co/Xenova/bge-small-zh-v1.5)
